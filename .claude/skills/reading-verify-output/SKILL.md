# When `pnpm verify` fails

Find the line `✘ verify failed at stage "<name>"` and use the matching entry. Fix the cause; never
loosen the gate.

| Stage                                      | Typical message                                                        | Correct fix                                                                                                                                                                          |
| ------------------------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| spec gate                                  | missing Status / plan points at unapproved spec                        | Ask the human to approve; do not edit the spec.                                                                                                                                      |
| format                                     | prettier differences                                                   | `pnpm format`                                                                                                                                                                        |
| lint: `@nx/enforce-module-boundaries`      | "A project tagged type:ui can only depend on…"                         | Move the code to the right layer or import via the allowed layer. See docs/architecture/boundaries.md. Never add a depConstraint.                                                    |
| lint: `@nx/dependency-checks`              | package X missing from peerDependencies                                | `pnpm nx run <project>:lint --fix`. If a package is "not used" but is imported: `pnpm nx reset` (stale graph).                                                                       |
| lint: `no-restricted-imports` deep import  | "Deep imports are banned"                                              | Export the symbol from the library's `index.ts` and import the alias.                                                                                                                |
| lint: `max-lines` / `complexity`           | file or function too large                                             | Split by responsibility (another file in the same lib, or a `type:util` lib).                                                                                                        |
| lint: `no-restricted-syntax` `.only/.skip` | focused/skipped test                                                   | Remove it; if the test is wrong, fix or delete it and say so in the PR.                                                                                                              |
| typecheck (build libs)                     | TS errors from `ng-packagr`                                            | Fix types; `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes` are on.                                                                                                       |
| unit tests                                 | failing specs                                                          | Fix the code, not the assertion, unless the spec changed (then the human re-approves).                                                                                               |
| traceability                               | test has no `[REQ-…]` / REQ has no test                                | Add the id to the title; write the missing test.                                                                                                                                     |
| dependency graph                           | `no-circular`, `features-are-leaves`, `no-server-only-in-browser-code` | Break the cycle via a `type:util` lib; features are reached only through routes; Node APIs only in `server.ts`.                                                                      |
| dead code                                  | knip unused export/file/dependency                                     | Delete it. If it is intentionally public API, export it from `index.ts`.                                                                                                             |
| design tokens fresh                        | src out of date                                                        | `pnpm tokens` and commit the output.                                                                                                                                                 |
| SSR build                                  | budget exceeded / prerender error                                      | Lazy-load, drop the dependency, or fix server-unsafe code (`window`, `document` without `isPlatformBrowser`).                                                                        |
| acceptance (e2e)                           | Playwright failures                                                    | Open the trace: `pnpm exec playwright show-trace dist/.playwright/apps/shell-e2e/test-output/**/trace.zip`. A 400 "Header host not allowed" means `allowedHosts`/`NG_ALLOWED_HOSTS`. |
| test weakening                             | tests removed / e2e edited with impl                                   | Restore the tests. Acceptance changes go in their own PR after the spec changes.                                                                                                     |
